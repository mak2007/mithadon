## 🚀 How to Run Locally

You can open `index.html` directly in any web browser:

```powershell
# Using default browser on Windows
Start-Process "C:\Users\Lenovo\.gemini\antigravity\scratch\mukesh-misthan-bhandar\index.html"
```

Or run a local development server:
```powershell
# Using Python (if available):
python -m http.server 8080

# Or via any local server extension in VS Code / Antigravity IDE
```

## 📱 Tech Stack
- **HTML5 & CSS3**: Pure semantic HTML5 and vanilla CSS custom properties (variables), Flexbox, CSS Grid.
- **JavaScript (ES6+)**: Zero-dependency reactive state management for cart, hamper customizer, portion pricing, and search filtering.
- **Lucide Icons**: Crisp vector icons.
- **Google Fonts**: `Cinzel`, `Plus Jakarta Sans`, and `Rozha One`.
